AI 應用規劃師模型菜示範中心

這裡把 iPAS AI 應用規劃師的官方資料、歷屆考題、自修題庫、學員 Prompt 與 GitHub Pages 發布流程整理成一個可教學、可追溯、可複製的模型菜示範中心。

課程定位

這不是單一練習網站，而是 FALO 針對台灣 AI 應用規劃師建立的模型菜示範中心，示範如何把官方 PDF 轉成 CSV 題庫、互動自修工具、可追溯資料庫與公開教材頁。

原本的題庫網站已保留在 `practice/`，作為其中一個可操作範例。

官方資料來源 -> PDF 封存 -> AI 抽題 -> CSV 清洗 -> 題庫 DB -> 自修網站 -> GitHub Pages 發布
