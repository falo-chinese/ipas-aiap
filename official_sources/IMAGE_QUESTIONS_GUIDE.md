## 💡 1. 處理策略與 AI 自動化架構說明 (Processing Strategy)

在全量 600 題大滿貫題庫中，共有 **52 題屬於「圖像依賴型題目 (Incomplete by Design)」**。這些題目包含盒鬚圖 (Box Plot)、混淆矩陣 (Confusion Matrix)、ROC 曲線、數學公式與 Python 程式碼截圖。為確保教材與線上測驗的最佳品質，我們採取的處理架構如下：

1. **300 DPI 超高清晰度自動採集 (PyMuPDF Automated Extraction)**：
   使用 Python 自動分析 12 本官方 PDF 原檔矩形座標 (Rect Bounding Box)，排除頁首頁尾浮水印後，將實體圖表、公式與程式碼精確裁切並導出為 300 DPI PNG 高畫質圖片。
2. **標準化 ID 典藏命名 (Standardized Naming Convention)**：
   圖片命名與題目編號 100% 一致（例如：`B3-002.png` 代表中級機器學習第 2 題吉尼不純度公式圖）。
3. **CSV 結構相容性擴充 (11th Column Schema Extension)**：
   在 `FALO-IPAS-AIAP-20260802.csv` 中擴充第 11 個欄位 `圖片檔名`（`image_filename`），向下相容舊版系統，同時為新版全圖文系統提供資料綁定。
4. **雙模式互動放大燈 (Interactive Lightbox Modal)**：
   在網頁前端 (`v3.01.html`) 的「複習閱覽」與「模擬考試」雙模式中，自動渲染高質感圖片卡片，並支援點擊全螢幕放大檢視，讓學生與講師清楚觀看小字程式碼與圖表細節。
